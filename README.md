# Customer Behavior Analytics

## Опис
Аналіз поведінки клієнтів на основі даних про замовлення з метою
визначення найбільш цінних сегментів клієнтів та зон росту бізнесу.

## Дані
- таблиці customers (демографія, місто, дата реєстрації)
- таблиці sales (замовлення, суми, дати)

## Основні метрики
- кількість замовлень на клієнта
- загальний дохід на клієнта
- середній дохід на клієнта
- сегментація клієнтів за активністю

## Сегментація клієнтів
Клієнти були розподілені на 3 категорії:
- inactive — 0 замовлень
- new — 1 замовлення
- active — 2+ замовлення

Це дозволило:
- чітко відокремити неактивну базу
- визначити ядро клієнтів, що генерує дохід

## Фінансові висновки
- Active-клієнти приносять найбільшу частку загального доходу
- Inactive-клієнти не генерують дохід, але є потенціалом для маркетингових кампаній
- New-клієнти формують точку росту бізнесу

Це типовий інсайт для:
- retention-стратегій
- email / push кампаній
- персоналізованих пропозицій

## Візуалізації
Побудовано графіки:
- розподіл клієнтів за статусами
- загальний дохід по статусах

Візуально видно:
- дисбаланс між кількістю клієнтів і доходом
- ключову роль active-клієнтів

## Бізнес-інтерпретація
- кількість клієнтів ≠ дохід
- основний дохід концентрується в активному сегменті
- бізнесу вигідніше утримувати клієнтів, ніж залучати нових

## Інструменти
- Python
- pandas
- matplotlib
